# Bayesian_model_01
# Updated: 7-Sept-2020

This repository contains the data sets and R code used in the following manuscript:

  Venarsky MP, Boone EL, Stewart-Koster B, Crook DA, O'Mara K, Woodhead J, Maas R, Bunn S In review. A Bayesian classification model to reconstruct lifetime movement patterns of riverine
fish using environmental tracers

All files are also available at https://doi.org/10.5281/zenodo.19171892

Email questions, comments, and ideas on how to improve either the analysis itself or the methodological description to Michael Venarsky
(mvenarsky@gmail.com). Meaningful contributions will be credited to the person.
